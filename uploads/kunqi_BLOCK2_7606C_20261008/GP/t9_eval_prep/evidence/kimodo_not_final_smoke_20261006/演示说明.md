# Kimodo → G1 适配 → SONIC 抓取演示

H100 已完成 ModelScope 文本编码器下载，并成功执行固定场景的完整流程。最终演示为服务器 `~/kimodo-g1-integration/outputs/demo_generation_006`，代码版本 `7e47fc6`。

## 输入与位置

Kimodo 的文本和运动学约束是独立输入。文本描述动作；准确触及指定物体时，空间目标需要由仿真、视觉或任务规划提供，不必写进文本，也不需要微调模型权重。机器人当前姿态用于初始姿态和坐标变换。

当前演示固定为左手抓取桌上的立方体，初始物块位置为 `[0.39,0.15,0.785]`。约束来自已验证专家轨迹：两个全身端点，以及双手、双脚各298个中间目标。独立的G1关节投影用这些密集目标约束机器人，Kimodo提供剩余自由度的运动先验；投影相对原始导出关节的变化为0.300rad RMSE。手指命令也来自已验证的独立控制器。这是经过强几何指导的集成演示，未证明任意提示词、任意物块位姿的自动抓取。

## 在H100复现

```bash
ssh hk
cd ~/kimodo-g1-integration
bash scripts/run_generation.sh 'A robot reaches forward with its left hand, grasps a small cube on a table and lifts it while standing still.'
```

默认自动选择空闲显存最多的GPU；可设置 `KIMODO_GPU=6` 指定卡。默认种子42。输出目录自动带时间戳。模型全部本地加载。

流程依次保存空间约束、Kimodo原始NPZ/CSV、关节适配参考、SONIC实际物理回放、独立验收结果和视频。每条生成样本按顺序尝试；不可达的适配样本或抓取失败均保留记录。
